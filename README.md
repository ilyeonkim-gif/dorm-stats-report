# 생활관 인원 누적 통계 · 결과보고서 📊

일일 인원 한글(.hwp) 파일을 업로드하면 **자동으로 누적**되고, 기간을 지정해 **결과보고서를 생성**하는 프로그램입니다.

**Python을 설치할 필요 없이** 바로 실행되는 **독립형 앱**입니다.

---

## 🚀 시작하기 (3단계)

### 1단계: 다운로드
- **[릴리스 페이지](../../releases)** 에서 자신의 OS에 맞는 파일 다운로드
  - **Windows**: `생활관통계보고서-windows.zip`
  - **macOS**: `생활관통계보고서-macos.zip`
  - **Linux**: `생활관통계보고서-linux.tar.gz`

### 2단계: 압축 해제
- 다운로드한 파일 압축 해제
- **권장**: 쉽게 찾을 수 있는 폴더 (예: 바탕화면)

### 3단계: 실행
각 OS별로 다릅니다:

#### Windows
```
생활관통계보고서.exe 더블클릭
```
- 검은 창이 나타나고 자동으로 브라우저가 열립니다
- 검은 창을 닫으면 프로그램 종료됩니다

#### macOS
```
생활관통계보고서.app 더블클릭 또는 더블클릭
```
- 처음 실행 시 "개발자를 확인할 수 없음" 경고가 나올 수 있습니다
  - [취소] → 다시 우클릭 → [열기] 클릭

#### Linux
```bash
# 터미널 열기
cd 다운로드폴더
chmod +x 생활관통계보고서
./생활관통계보고서
```

## 📱 사용 방법

### ① 일일 파일 업로드
1. 생활관 일일 인원 기록 한글(.hwp) 파일 준비
2. 웹 페이지의 드래그&드롭 영역에 파일 끌어다 놓기
   - 여러 파일 한 번에 가능
   - 같은 날짜는 새 파일로 교체됨

### ② 기간 결과보고서
1. 시작일 / 종료일 선택
2. [📄 보고서 만들기] 클릭
3. 화면 상단의 [🖨️ 인쇄 / PDF로 저장] 클릭
4. 인쇄 대화창에서 "PDF로 저장" 선택

### ③ 엑셀 다운로드
- 기간별 원자료(일자별·학년별·사유별·심야자습·특이사항)를 엑셀 파일로 다운로드

## 🛠️ 기술 정보

### 의존성
- Python 3.9+
- Flask 2.3.3
- olefile 0.47 (한글 HWP 파일 읽기)
- openpyxl 3.1.5 (엑셀 생성)

### 데이터
- **저장 위치**: 실행 폴더의 `dorm_stats.db` (SQLite 데이터베이스)
- **백업**: `dorm_stats.db` 파일을 복사하면 됩니다
- **이전**: 폴더 전체를 다른 PC에 복사하면 같은 데이터로 이용 가능

### 웹 주소
- 로컬 주소: `http://127.0.0.1:5050`
- 다른 장치에서 접근 불가 (로컬 전용)

## ⚠️ 주의사항

### 파일 형식
- ✅ `.hwp` (한글 2002 이후 형식): 지원됨
- ❌ `.hwpx` (한글 2014+): 지원 안 됨
  - 한글에서 [파일] → [다른 이름으로 저장] → HWP 형식으로 변환 후 업로드

### 보안 경고
- **Windows**: "Windows에서 보호했습니다" 메시지
  - [추가 정보] → [실행] 클릭
  - (PyInstaller로 빌드한 파일이라 나타나는 거짓 양성 경고입니다)
- **macOS**: "개발자를 확인할 수 없음" 경고
  - 우클릭 → [열기] 선택

### 문서 양식
한글 문서의 다음 요소가 있어야 인식 가능:
- 현인원/총인원 표
- "귀가", "외박" 구분
- "특이사항(학생)", "특이사항(민원)" 섹션
- 학년별 현황 (선택)
- 심야자습 표 (선택)

## 🔧 개발자용: 로컬 빌드

### 준비
```bash
git clone <저장소>
cd 생활관통계보고서
pip install -r requirements.txt pyinstaller
```

### 빌드

#### Windows
```
build_windows.bat 더블클릭
```

#### macOS/Linux
```bash
chmod +x build_mac_linux.sh
./build_mac_linux.sh
```

### 결과
- `dist/` 폴더에 실행 파일 생성
- 배포: `dist` 폴더 전체를 압축
